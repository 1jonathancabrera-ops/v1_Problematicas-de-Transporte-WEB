# Método Esquina Noroeste
En este caso elegí el Método de la Esquina Noroeste, aunque la forma de usar la web es la misma para ambos métodos, lo único que cambia es
la forma en la que el programa resuelve el problema cosa que veremos más adelante.

En esta parte el usuario debe ingresar la cantidad de Ofertas y de Demandas, una vez hecho esto, el usuario tiene que presionar el botón de 
**"Generar Tabla"**.
<div style="text-align:center">
<img width="1361" height="767" alt="image" src="https://github.com/user-attachments/assets/129e5ae4-faa5-4c15-99c7-75e3ac67fbdb" />
</div>


Luego de presionar dicho botón, se genera esta tabla donde el usuario debe completar en cada casillero o celda, con el valor que tendrá 
cada cada costo, además deberá ingresar el valor de cada oferta y cada demanda.

Una vez el usuario complete todos los datos debe presionar el botón de **"Validar Totales"**, este botón lo que hace es asegurarse de que los valores ingresados 
sean válidos (el programa toma por inválido cualquier número negativo), después suma el total de los valores de ofertas y de demandas, y compara si el total
de ofertas es igual al total de demandas.
<div style="text-align:center">
<img width="1365" height="710" alt="image" src="https://github.com/user-attachments/assets/d12baa64-d9a9-497d-9316-150d6853c100" />
</div>


En este caso, muestra el resultado y da un aviso de que **"no está balanceado"**, es decir la oferta total y demanda total no son iguales, 
para poder continuar el programa da la opción de agregar un "valor ficticio" para balancear los totales.

El usuario a partir de acá puede dar por terminado el problema, lo que puede hacer es presionar el botón de **"Reiniciar"** si quiere hacer otro
problema con el mismo método  con diferentes valores, o puede presionar el botón de **"Volver a Inicio"**, este botón lo lleva al usuario
a la pantalla de inicio por si quiere cambiar al método de **"Menor Costo"**.
