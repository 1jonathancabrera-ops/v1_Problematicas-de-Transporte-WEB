# Problema de Transporte



Aplicación web desarrollada para resolver problemas de transporte
mediante diferentes métodos de optimización.

## Métodos disponibles

- Esquina Noroeste
- Menor Costo

## Tecnologías

- HTML
- JavaScript

## Funcionalidades

- Carga de ofertas y demandas
- Carga de costos
- Validación del problema
- Resolución mediante Esquina Noroeste
- Resolución mediante Menor Costo
- Problemas balanceados y no balanceados
- Origen/destino ficticio
- Cálculo de la solución inicial

## Proyecto

Proyecto académico realizado para la materia Modelos y Sistemas.
